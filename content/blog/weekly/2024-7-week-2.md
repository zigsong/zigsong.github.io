### CSS 프로퍼티의 초깃값(Initial Value)

- 스펙에 명시된 기본값
- 상속되는 프로퍼티냐 아니냐에 따라, 초깃값 사용여부가 결정된다.
  - 상속되는 프로퍼티 (inherited properties)
    - 초깃값이 root 에만 적용된다
  - 상속되지 않는 프로퍼티 (non-inherited properties)
    - 초깃값이 모든 element에 적용된다.

예시
  - `color`
    - 초깃값은 `canvastext`
    - 상속됨 -> 초깃값이 root에만 적용된다. 
  - `background-color`
    - 초깃값은 `transparent`
    - 상속 안됨 -> 초깃값이 모든 element에 적용된다. 

> 초깃값으로 지정하기
> `initial` 키워드를 사용해 명시적으로 초깃값을 지정할 수 있다.

### `pnpm catalog`

모노레포의 dependency를 고정해준다.

```yaml
# pnpm-workspace.yaml

packages:
  - packages/*

# Define a catalog of version ranges.
catalog:
  react: ^18.3.1
  redux: ^5.0.1
```

### `pnpm --filter`

- `pnpm --filter ...foo test`
  - `foo`와 `foo`에 의존하는 패키지들의 test 실행

- `pnpm --filter "...^foo" test`
  - `foo`에 의존하는 패키지들의 test 실행

### Protocol-Relative URL (`//`)

e.g. `@import url(//atelier-assets.baemin.com/font/css/SpoqaHanSansNeo.css)`

- 현재 페이지의 프로토콜에 따라 폰트 파일을 가져온다.
  - 그래서 http일 수도 https일 수도 있다.

- 언제 쓸까?
  - Mixed Content 차단 경고를 피하는 데 유리

- 언제 안쓸까?
  - 보안이 중요한 경우, https://로 명시하는 것이 적합
