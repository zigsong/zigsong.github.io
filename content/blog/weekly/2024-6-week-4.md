###  `<input>` 의 `capture` 속성

`type`이 `file`이고, `accept` 속성이 정의되어있을 때, `capture`를 사용해 카메라나 마이크와 같은 미디어 사용을 요청할 수 있다.

사용할 수 있는 `accept` 속성 값은 다음과 같다. 
- image/*
- video/*
- audio/*

`capture` 속성값에는 두 가지가 있다. 
- `user`: 전면 카메라 우선 사용
- `environment`: 후면 카메라 우선 사용
  - cf) 모바일에서만 지원하기 때문에 데스크탑에서 사용 시 파일 선택 창이 열린다. 

> 카메라 기능 웹으로 구현하기
> HTML5의 `getUserMedia` API를 사용한다.

### Prompt API for Gemini Nano가 탑재된다고 합니다

Chrome에 Prompt API for Gemini Nano가 탑재된다고 한다. (아직은 Chrome Canary에서만 사용 가능)

```jsx
const canCreate = await window.ai.canCreateGenericSession()

if (canCreate !== "no") {
    const session = await window.ai.createTextSession();
    const stream = session.promptStreaming("Tell me a joke!")
    for await (const chunk of stream) {
        console.log(chunk)
    }
    session.destroy()
} else {
    console.error(" can't create generic session", canCreate)
}
```

**Ref** https://afficone.com/blog/window-ai-new-chrome-feature-api/
